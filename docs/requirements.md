# 轨迹友好视图 — 需求文档

> 项目：dsh-trail（DeepSeek Harness 开源 out-of-tree bundle）
> 状态：草案 v0.1（动态原型验证前）
> 语言：简体中文；发布版补英文

## 1. 背景与痛点

以下痛点是从 `@deepseek-ai/dsh-client-ui-trajectory` 源码推断的**假设**，需经原型实测与用户反馈验证。证据：

| # | 痛点假设 | 代码证据 |
|---|---|---|
| P1 | 术语不翻译、无解释 | `locales.ts` 中文词典 14 个键中 9 个是英文原文（Duration、Turns、Calls、Expand turns…）；TTFT、compaction 等术语界面无图例 |
| P2 | 功能面过宽 | 工具栏 5 个控件（耗时切换/实际时间/Turns 折叠/Calls 折叠/搜索）+ Overview 时间轴（拖选区间、滚轮缩放、右键平移）+ 独立检查器，全部是专家功能 |
| P3 | 无故事线 | 主视图是「索引/事件/内容」三列事件表，按事件罗列；缺少"我问了什么 → AI 怎么想 → 做了什么 → 结果如何"的叙事 |
| P4 | 中间过程是噪声 | 思考块、工具参数的原始 JSON 与回复正文同级并列，无视觉层级 |
| P5 | 无引导 | 无图例、无说明文案、无空状态教学 |

**验证方式**：本会话动态原型实点反馈（阶段 1）；开源后社区 issue（阶段 3）。

## 2. 目标与非目标

### 目标

- 新用户打开「轨迹」页签后 30 秒内看懂：AI 每一步在做什么、每轮问答的来龙去脉。
- 以独立开源插件替换原轨迹视图，**不修改 DeepSeek Harness 产品代码**。

### 非目标

- 不改聊天页签、不改输入区。
- 不做设置开关、主题定制；v1 仅简体中文（发布版补英文）。
- 不新增 Host 侧数据接口——全部数据来自现有客户端会话快照。
- 不与原轨迹视图功能对等（原高级功能的去留见 FR-5，已由用户拍板）。

## 3. 用户故事

1. 作为新用户，打开轨迹页签，看到一条自上而下的「故事线」：每轮问答一张卡片，能看到我问了什么、AI 怎么回答。
2. 作为新用户，遇到不认识的工具名（read、grep），卡片显示中文名和一句话解释。
3. 作为新用户，看到「思考中…」「正在运行工具 X」，知道 AI 在工作而不是卡住。
4. 作为好奇用户，点击「详情」能看到原始参数、token 用量、耗时。
5. 作为用户，用顶部搜索框快速定位某轮或某个工具。
6. 作为老用户，卸载插件后原轨迹视图完整恢复。

## 4. 功能需求（FR）

- **FR-1 替换轨迹页签**：注册 `conversation.view`，`id: 'trajectory'`，标签「轨迹」；bundle 的 patch 同时 `disabled: true` 掉 `ui-trajectory` 行，避免双占用同 id。
- **FR-2 回合分组**：按 `seq` 顺序将节点分组为回合卡片。`user` 节点开启新回合；`assistant`/`tool-result`/`context`/`compaction`/`steering`/`turn-error` 等归入当前回合；`assistant` 节点携带的 `turn` 字段校正回合号。
- **FR-3 步骤渲染**：卡片内按序渲染：你（问题）/ AI 回复 / 思考（默认折叠）/ 工具调用 / 工具结果（✓/✗）/ 上下文注入 / 历史压缩 / 补充说明 / 出错 / 自动重试。
- **FR-4 工具中文映射**：内置「工具名 → 中文名 + 一句话说明」映射表（见 design.md §5，覆盖当前工具集）；未知名回退「调用工具 `<name>`」。
- **FR-5 折叠与详情（原高级功能取舍）**：长文本（>200 字符）截断可展开；思考默认折叠；每行「详情」展开原始参数、结果预览、token、耗时；顶部保留一个搜索框（按关键字过滤回合）。**删除**：时间轴 Overview、拖选/缩放/平移、Duration/实际时间开关、Turns/Calls 批量折叠、独立检查器。
- **FR-6 实时渲染**：`partial` 与 `runningCalls` 实时更新；进行中回合显示状态徽标（正在思考 / 正在运行工具 / 正在回复）；不虚构耗时。
- **FR-7 回合 meta**：卡片头显示耗时（`turnTimings`）、模型（`provenance.model`）、token 合计（`usage` 求和）；缺失字段不显示，不兜底造假。
- **FR-8 分页**：`hasMore` 时显示「加载更早记录」；`loadingOlder` 时禁用；`openState === 'loading'` 显示加载态。
- **FR-9 空状态**：无节点时显示引导文案与图例。
- **FR-10 错误与中断**：`turn-error` 显示错误信息；`interrupted` 助手节点标记「已停止」；错误工具结果显示 error 摘要。
- **FR-11 卸载恢复**：停用动态原型 / 移除 bundle 后，原轨迹视图恢复（slot 占用随 fiber 移除）。

## 5. 验收标准（AC）

- AC-1 新会话打开轨迹页签 → 显示空状态引导，无报错。
- AC-2 完成一轮问答 → 出现一个回合卡片，含用户问题与 AI 回复，卡片头有耗时。
- AC-3 运行中回合 → 状态徽标随阶段变化；回合结束后徽标消失。
- AC-4 长回复 → 截断并显示「展开」；点击后显示全文。
- AC-5 工具调用行 → 显示中文名；点击「详情」可见原始参数。
- AC-6 搜索「grep」→ 仅显示含该关键字的回合；清空后恢复全部。
- AC-7 点击「加载更早记录」→ 窗口前移；加载中按钮禁用。
- AC-8 停止动态原型 / 移除 bundle → 轨迹页签恢复原样。
- AC-9 打开含错误的会话 → 错误回合友好呈现，不白屏。

## 6. 风险

- R1 **分组启发式**：`user`/`tool-result` 节点无 `turn` 字段，按 seq 顺序推断可能把边界画错 → 用例覆盖 + 原型实测。
- R2 **legacy 字段是兼容投影**：顶层 `nodes`/`partial`/`runningCalls`/`turnTimings` 是产品为兼容保留的字段，未来可能移除 → 插件声明支持的 dsh 版本范围，README 说明。
- R3 **版本耦合**：插件依赖 `@deepseek-ai/*` peer 包，版本漂移会失配 → peerDependencies 声明范围，安装时校验。
- R4 **删除原高级功能不可逆**（仅对本插件覆盖范围）→ 已由用户拍板：折叠进详情 + 保留搜索。
- R5 **out-of-tree bundle 注入 dsh.client 行未端到端验证** → 阶段 2 先做最小 bundle 冒烟再全量实现。

## 7. 测试策略

- **原型阶段（动态插件）**：真机点检 AC-1…AC-9 + cordis inspect 诊断。
- **开源包阶段**：vitest 组件测试（纯 props 驱动，覆盖分组、映射、折叠、搜索过滤）；类型检查；`pnpm build` 产物冒烟。
- **发布阶段**：GitHub Actions CI（lint/typecheck/test/build）；安装文档附带录屏 GIF。
